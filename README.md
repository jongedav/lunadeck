# Rlayed

Rlayed is an open, modular gaming ecosystem that transforms your existing PC into a self-hosted handheld gaming experience. Its independent applications work together to make remote gaming seamless, from launching games to managing displays, performance, and sessions.

## Development

Build the Rlayed CLI:

```sh
go build -o rlayed ./cmd/rlayed
```

Run the tests:

```sh
go test ./...
```
